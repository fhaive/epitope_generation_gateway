# Figure source data

This directory contains processed numerical source data underlying Figures 2, 3,
and Supplementary Figures S2-S8 of the manuscript:

**Epitope Generation Gateway (EGG): A biological context-dependent approach to
cancer vaccine development**

The numerical source-data files in this directory and its subdirectories are
released under the Creative Commons CC0 1.0 Universal Public Domain Dedication
(`CC0-1.0`). This applies to processed CSV, TSV, and TSV.GZ source-data tables.

Source code, plotting scripts, workflow files, and the rest of the repository
remain under the repository-level GPL-3.0 licence unless otherwise stated.

## Included figure-source data

- `Figure2/`: numerical source data for Figure 2.
- `Figure3/`: numerical source data for Figure 3.
- `FigureS2/`: numerical source data for Supplementary Figure S2.
- `FigureS3/`: numerical source data for Supplementary Figure S3.
- `FigureS4/`: numerical source data for Supplementary Figure S4.
- `FigureS5/`: numerical source data for Supplementary Figure S5.
- `FigureS6/`: numerical source data for Supplementary Figure S6.
- `FiguresS7-S8/`: numerical source data for Supplementary Figures S7 and S8.
