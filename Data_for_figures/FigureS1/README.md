# Supplementary Figure S1 source data

This directory contains the numerical source data underlying Supplementary Figure S1.

Supplementary Figure S1 shows the relationship between mutation or fusion burden and predicted neoantigen yield across the TCGA-SKCM cohort.

## Files

- `Supplementary_Figure_S1_source_data_by_sample.tsv`  
  Per-sample values used for the plotted scatterplots.

- `Supplementary_Figure_S1_spearman_correlations.tsv`  
  Spearman correlation statistics for the plotted comparisons.
