# Figure 2 source data

This directory contains the numerical source data underlying Figure 2.

Figure 2 summarises the number of SNVs, indels, fusions, and combined alteration counts detected per TCGA-SKCM sample.

## Files

- `Figure2_source_data.csv`  
  Per-sample SNV, indel, and fusion counts used to generate the plotted panels.
