# Figure 3 source data

This directory contains the numerical source data underlying Figure 3.

Figure 3 summarises candidate neoantigen counts per patient by MHC class and variant category.

## Files

- `figure3_source_data.csv`  
  Per-sample candidate neoantigen counts stratified by MHC class and variant category.
